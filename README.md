## 🚀 Featured Project

### AI-Powered Job Recruitment Portal — Full-Stack (React.js + Python)

- LLM-powered recruitment platform where candidates upload resumes and receive AI-generated job matches **with an explanation of why each role fits**
- Integrated an LLM API to parse unstructured resumes into structured JSON (skills, experience, education) and score candidate–job fit — replacing brittle keyword matching with semantic understanding
- Designed RESTful APIs for authentication, job listings, and applications; modeled and persisted data in MySQL
